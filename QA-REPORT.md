# Проверка WATANABE STUDIO 1.3 — TOKYO DIGITAL

Локальная копия на ветке development. Проверка в Google Chrome через Playwright.

| Сценарий | Результат |
|---|---|
| Уход курсора с иллюстрации | В версии 1.2 обработчик сразу обнулял смещение внешнего слоя. В версии 1.3 браузер интерполирует его transform. В четырёх циклах расстояние до центра монотонно уменьшалось до менее 0,002 px за 665, 665, 665 и 662 мс. Длительность перехода в CSS — 680 мс. |
| Повторный вход до завершения возврата | Через 130 мс возврата наведён курсор на противоположную сторону. Расстояние до центра в соседних замерах изменилось с 7,02 до 6,36 px. Мгновенного переноса к новой цели не обнаружено. |
| Остальные анимации | Матрицы трансформации обеих орбит и пульсирующего ядра менялись. При ручной паузе орбита остановилась, параллакс сбросился. При эмуляции reduced motion длительность перехода составила 0 с. |
| Карточка Easy Language | На ширинах 1440, 768, 390 и 320 px проверены RU и EN, текст описания и кнопка, отсутствие горизонтальной прокрутки. Проверена двухколоночная и одноколоночная раскладка. Просмотрены снимки карточки на ширинах 1100 и 390 px. |
| Ссылка бота | Кнопка открыла новую вкладку с указанным адресом (в тесте навигации внешний запрос перехвачен). Отдельный запрос к публичной странице вернул HTTP 200, заголовок Telegram: Launch @easy_language_bymyself_bot и ссылку запуска для того же имени. |
| Регрессия | Проверены сохранение английского языка при перезагрузке, закрытие мобильного меню после выбора раздела, раскрытие и сворачивание услуг и FAQ клавишей Enter. В разметке три прежние ссылки на @atlaaa и три карточки проектов. Браузерный сценарий завершился без исключений JavaScript. |

Телефоны и планшеты проверены по размерам области просмотра. Физические устройства, Safari и Firefox в прогон не входили. Общение с ботом и его внутренние функции не тестировались. Ниже сохранены результаты предыдущей версии.

# Проверка WATANABE STUDIO 1.2 — TOKYO DIGITAL

Проверена локальная рабочая копия в ветке `development`. Сайт обслуживался обычным HTTP-сервером на 127.0.0.1. Браузерные проверки выполнены в настольном Google Chrome через Playwright.

| Проверка | Наблюдение |
|---|---|
| Адаптивность | На 1440×900, 768×1024, 390×844 и 320×640 проверены русский и английский режимы. Ширина документа укладывается в область просмотра. Ссылки меню ведут к своим разделам. |
| Визуальная проверка | Просмотрены снимки первого экрана 1280×800 и 390×844. На телефоне текст и сфера расположены последовательно. Нижняя подпись иллюстрации перенесена влево, чтобы освободить место для плавающей кнопки. |
| Навигация и язык | Проверены мобильное меню, закрытие клавишей Escape, переход к началу страницы и сохранение английского языка после перезагрузки. |
| Услуги и FAQ | Все четыре карточки услуг и три ответа FAQ раскрываются и сворачиваются с клавиатуры. |
| Telegram | Три ссылки открывают новую вкладку с адресом https://t.me/atlaaa. Запрос к внешнему сервису перехвачен тестом. Без JavaScript все три ссылки присутствуют в разметке. |
| Движение | В браузере проверены изменение матрицы орбиты, смещение при движении указателя, наклон карточки, появление заголовка проектов и пауза. В режиме уменьшенного движения анимации орбит и строки отключены. |
| JavaScript | Синтаксис проверен через `node --check script.js`. Браузерный сценарий завершён без необработанных исключений. |
| Плавность | В двухсекундной выборке на главном экране при 1280×800 получено около 60 вызовов requestAnimationFrame в секунду. Это показатель одного прогона в настольном Chrome. |

## Ограничения

Размеры телефона и планшета воспроизводились изменением области просмотра Chrome. Физические устройства, Safari, Firefox и длительная нагрузка на слабом оборудовании не проверялись. Замер кадров не оценивает время загрузки у посетителя. Проверка Telegram охватывала переход по ссылке; запуск приложения и доставка сообщений не проверялись. Версия 1.2 проверена локально, публикация на GitHub Pages не выполнялась.
Контрольный прогон на ширине 390 px после правки подписи подтвердил свободное место между подписью и кнопкой. Все якоря имеют цели. Время до завершения загрузки страницы в этом локальном прогоне — 1,14 с.
