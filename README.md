# WATANABE STUDIO — TOKYO DIGITAL v1.3

Двуязычный статический сайт студии. Рабочая версия находится в ветке `development`. Основные разделы — услуги, демо-проекты, этапы работы, студия, FAQ и контакты.

## Локальный просмотр

Из корня рабочей копии запустите:

```sh
python -m http.server 8120 --bind 127.0.0.1
```

Откройте [сайт на этом компьютере](http://127.0.0.1:8120/). Остановить сервер в терминале можно сочетанием Ctrl+C. Для простого просмотра также можно открыть `index.html` напрямую.

## Интерфейс

- Красная SVG-сфера пульсирует, две орбиты вращаются с разной скоростью. При движении указателя иллюстрация плавно догоняет его относительно сетки. При выходе курсора слой возвращается к центру за 680 мс. Повторное наведение меняет цель из текущего положения.
- Строка направлений движется непрерывно. Заголовки и элементы разделов появляются при прокрутке, карточки услуг реагируют на указатель и раскрываются нажатием.
- Кнопка паузы управляет движением. Системная настройка уменьшения движения отключает анимации и плавную прокрутку. На сенсорных устройствах без точного указателя эффекты наклона отключены.
- Кнопка «Обсудить проект», плавающая кнопка и контакт внизу страницы открывают [Telegram студии](https://t.me/atlaaa). Адреса заданы в HTML и работают при отключённом JavaScript.
- Переключатель RU/EN сохраняет выбранный язык в браузере. Мобильное меню поддерживает Escape. Услуги и FAQ раскрываются с клавиатуры.

## Файлы и размещение

| Файл | Назначение |
|---|---|
| `index.html` | Разметка, тексты RU/EN, ссылки, SVG-сфера |
| `style.css` | Адаптивная сетка, цвета, анимации и режим уменьшенного движения |
| `script.js` | Язык, меню, пауза, реакции на указатель и видимость разделов |
| `logo.svg` | Фирменный знак |
| `QA-REPORT.md` | Выполненные проверки и ограничения |

Для GitHub Pages достаточно статических файлов из корня репозитория. Пути к ресурсам относительные. Сборка, ключи API и пакетный менеджер не требуются. При доступе к Google Fonts загружаются Unbounded и Manrope, при недоступности используются системные шрифты. В портфолио сохранены две идеи демо-проектов и добавлен действующий демонстрационный проект [Easy Language](https://t.me/easy_language_bymyself_bot) — Telegram-бот для самостоятельного изучения иностранных языков. Кнопка карточки открывает публичную ссылку в новой вкладке.
