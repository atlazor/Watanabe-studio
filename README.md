# WATANABE STUDIO — TOKYO DIGITAL v1.1

Учебный статический сайт. Откройте index.html в браузере или запустите `python -m http.server 8000` в папке проекта и откройте http://localhost:8000. Сервер для работы сайта не обязателен.

## Файлы
- index.html — структура, русский и английский тексты.
- style.css — оформление, адаптация и анимации.
- script.js — переключение языка, меню и настройка Telegram.
- logo.svg — векторный знак.

## Перед публикацией
1. В script.js задайте TELEGRAM_USERNAME (публичный username без @). Пока он пуст, сайт честно сообщает, что контакт не добавлен.
2. Замените идеи демонстрационных проектов настоящими демо после их создания.
3. Проверьте тексты, контакты, мобильный вид и соответствие требованиям законодательства для вашего бизнеса.

## GitHub Pages
Создайте репозиторий и загрузите содержимое папки в его корень. В настройках Pages выберите Deploy from a branch, ветку main и папку / (root). После публикации GitHub покажет адрес сайта. Доступность зависит от настроек репозитория и аккаунта.

Шрифты Unbounded и Manrope загружаются с Google Fonts, при отсутствии интернета используются системные шрифты. Нет сервера, базы данных, форм сбора данных или подключенного ИИ. Сайт не опубликован автоматически.
